# QR code card

A Frontend Mentor challenge built with Next.js, React and Tailwind. The supplied QR image remains unchanged. A visible text link makes the destination accessible without a camera.

## Development

Install with `npm install`, then run `npm run dev`. Check with `npm run lint`, `npm run build` and `npm run typecheck`.

## Design and data

[Official challenge](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H) and [starter source](https://github.com/frontendmentorio/qr-code-component). Reference JPEGs remain in the source packet. Body copy follows the family's 16px floor rather than the original 15px specification. The card has no account, database, analytics, or application state. Images and copy are supplied by Frontend Mentor; application code and the tab icon are authored for this project.
